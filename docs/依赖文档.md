# 项目依赖文档

## 概述
本文档记录了 translate-transfer 项目的所有 Python 依赖包及其版本信息。

## 环境设置
- Python 版本: 3.x
- 虚拟环境: venv
- 包管理器: pip

## 安装步骤

### 1. 创建虚拟环境
```bash
python3 -m venv venv
```

### 2. 激活虚拟环境
```bash
source venv/bin/activate  # Linux/macOS
# 或
venv\Scripts\activate     # Windows
```

### 3. 安装依赖
```bash
pip install -r requirements.txt
```

### 主要功能
1. **Flask**: 提供 Web 服务器和路由功能

## 开发建议

### 添加新依赖
```bash
pip install <package-name>
pip freeze > requirements.txt  # 更新依赖文件
```

### 更新依赖
```bash
pip list --outdated  # 查看过期包
pip install --upgrade <package-name>  # 更新特定包
pip freeze > requirements.txt  # 更新依赖文件
```

### 清理依赖
```bash
pip uninstall <package-name>
pip freeze > requirements.txt  # 更新依赖文件
```

## 环境验证

### 检查虚拟环境
```bash

```

### 验证依赖安装
```bash
pip list  # 列出所有已安装包
python -c "import flask, requests; print('所有依赖导入成功')"
```

## 常见问题

### 1. 虚拟环境未激活
确保在虚拟环境中运行：
```bash
source venv/bin/activate
```

### 2. 依赖冲突
如果遇到版本冲突，可以创建新的虚拟环境：
```bash
rm -rf venv
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. 网络问题
如果 pip 安装失败，可以更换镜像源：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```
